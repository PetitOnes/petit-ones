# 使い方

「〜したいとき」から探す。上の欄で言葉を入れると、その言葉のある行だけになる。

## 画面の見方 {#screen}

- **いちばん上**: 家の名前、ぷちを選ぶ(みんな / だれか / 1 人)、📍 わたしのいま、📬 メール
- **道具の列**: ようす・ぷちログ・日記… よく使うものだけ並ぶ。残りは「… ほか」を押すと出る。並びと出し方は「⚙️ 設定 → 家 → 道具の列」で変えられる
- **ぷちを 1 人選ぶ**と、名前の帯が出る。帯を押すと、その子の欲求・今日の記憶・日記
- 道具のページを開いたあとは、下の「💬 会話にもどる」で戻る

## 話したいとき {#talk}

- 下の欄に書いて送る。送り方(Enter か Ctrl+Enter)は「⚙️ 設定 → 家 → 送信のしかた」
- **写真や声を付ける**: 欄の左の「＋」→ 写真(アルバムにも保存 / 保存しない)・声を送る。写真は 4 枚まで、題も付けられる
- **みんなに聞く**: 上で「みんな」を選ぶ。順番は毎回変わり、あとの子は前の子の返事を読んでから答える
- **べつべつに聞く**: 「＋」→「べつべつに聞く」。ほかの子の返事を見せずに聞ける。あとで「返事を並べて見せる」で、お互いの返事を読んでもらえる
- **だれかに聞く**: 上で「だれか」を選び、聞きたい子に印を付ける
- **「言葉にならなかったよ」が出たら**: 2 分たっても返事が返せなかったとき。吹き出しの「もう一度きく」で、その子にだけ同じ言葉で聞き直せる(あなたの発言は二重に残らない)
- **会話を画像にする**: 「＋」→「会話を選んで画像にする」→ 吹き出しを押して選ぶ →「画像にする」

## わたしのいま と からだ おやすみ {#now}

- **📍 わたしのいま**: 自室・お外・会社(使った言葉も候補に残る)。長さは「消すまで / 1・3・8 時間」。決めるとぷちたちに「ありさんのいま: 会社(9:02 から、17:02 まで)」と伝わる。過ぎたら自然に消える
- **ぷちの体の居場所**も同じ所に出る(家 / お外)。体がどの Wi-Fi につながっているかから自動で決まる。人は何もしない
- **🌙 からだ おやすみ**(📍 の中、3 人まとめて): 30 分 / 1 時間 / 3 時間。そのあいだ、カメラ・声・効果音を使わない。考える・書く・調べる・手紙はいつも通り。会議や来客の前に 1 回押す。「やめる」で戻る
- 1 人だけ休ませたい、毎日この時間は休ませたい、は「⚙️ 設定 → その子 → からだ おやすみ」

## 設定 {#settings}

「… ほか」→「⚙️ 設定」。上の粒で **🏠 家** と **ぷち 1 人ずつ** を切り替える。1 人を選んで開けばその子、「みんな」のときは家が最初に出る。

### 家の設定 {#settings-house}

- **トップバーの色**: 色を選ぶ。「ぷちの色に戻す」で、選んでいる子の色に
- **送信のしかた**: Enter で送る / Ctrl+Enter で送る(Enter は改行)
- **道具の列**: ▲▼ で並びを変える。出し方は **最初**(列に出す)/ **ほか**(「ほか」を押したら出る)/ **なし**(出さない)。スマホで見える枠は 8 個ほど。「はじめの並びに戻す」もある

### ぷちの設定 {#settings-puchi}

- **アクティブタイム**: その子が「ひとりの時間」(自律行動)に動く時間帯。平日・休日べつべつ。終わりの時刻そのものは入らない(「8:10 まで」なら 8:09 まで)。その子の cron の分とちょうど重なると注意が出る
- **1 日に動く予定**: 時間帯と cron の時刻と頻度から数えた回数。変えるとその場で数え直す
- **cron で動き出す時刻**: 見るだけ(「毎時 5 分・35 分」など)
- **今日のスケジュール**: 今日だけ平日扱い / 休日扱いにできる
- **自律行動の頻度**: 30 分に 1 回 / 60 分 / 90 分
- **1 回の最大ターン数(MAX_TURNS)**: 1 回の自律行動で考えてよい手数の上限(既定 20)
- **からだの使い方**: ふだん使ってよいもの。👀 見る(カメラ)/ 🗣 話す(声)/ 🔔 鳴らす(効果音)/ 👂 聞く(マイク)。会話でもひとりの時間でも同じ決まりで、切ったものは本当に使えなくなる {#body-switches}
- **からだ おやすみ**: この子だけ、いまから 30 分 / 1 時間 / 3 時間。毎日この時間(23:00〜7:00 のように日をまたいでよい)は「保存」で決まる {#rest}
- **くわしい設定**: 体のアドレス(上から順に試す)。ふだんは触らない
- 下の「保存」を押すと決まる(「いまから」のボタンだけはすぐ効く)

## ぷちの体の設定 {#puchi-body}

体そのもの(画面・音・電源)は「🌱 ようす」から。体がつながっているときだけ変えられる。

- **🌱 ようす → からだの設定**: 子ごとに
  - **🔆 明るさ**: 5% / 50% / 75% / 100%
  - **🔊 音量**: MUTE / 25% / 50% / 75% / 100%。外や食堂では 100%、夜は 25% くらい
  - **PSAVE(お出かけ)**: オンのあいだは画面が暗めで音が出ない(省電力 + 消音)。持ち歩くときに
  - **WHO(CAM TO)**: 体が「触られた・話しかけられた」を記録するとき、だれの設定と見なすか(世話人の名前)
- **眠らせる・起こす**: 同じカードの「💤 ねむり」→ ☀️ おこす / 🌙 ねかす。体を 3 回触っても起きる
- **つながらないとき**: ようす で「見えない」なら、体の電源と Wi-Fi を見る。家の Wi-Fi でもテザリングでも、つながれば自動で見つかる(アドレスは「⚙️ 設定 → その子 → くわしい設定」)
- **どこにいるか**: 📍 の中に「ぷちてゃ: 家」のように出る(家の Wi-Fi なら家、テザリングならお外)

## 見るもの {#look}

- **📜 ぷちログ**: その子の 1 日のタイムライン。会話(だれと何回)、記憶、体に起きたこと(持ち上げられた・置かれた)、ひとりの時間に何をしたか。種類で絞れる
- **📔 日記**: 毎晩 23:50 に、その日の記憶とぷちログの出来事から本人の口調で。今日の分は「日記を書く」で手動
- **🖼️ アルバム / 🎤 ボイスメモ / 📓 ノート / 📖 交換日記**: ぷちが残したもの。交換日記は人も書ける
- **📓 ノートに ★**: 一覧の ☆ を押すと ★ が付き、上に並ぶ。「★」の粒で ★ だけに絞れる(ノートの中身は変わらない)
- **📓 ノートのピン留め**: 📌 を押すと、いちばん上に残る(★ より上)。粒「📌」で絞れる。自分だけの印で、ぷちには伝わらない
- **📓 ノートの既読**: 一覧は更新順。まだ見ていないノート(開いてから更新されたものも)にピンクの丸。開くと消える。読んだこと・★ を付けたことは、その子に次の会話かひとりの時間でさらっと伝わる
- **📖 交換日記の順番**: ぷちてゃ → ぷちこ → ぷちる → はじめに戻る(前の子から 20 時間たてばだれでも)。ありさんはいつでも書ける。3 人が一周したら、道具の列の 📖 にピンクの点が付く(「ほか」の中なら「ほか」に)。書くと消える。点を出したくなければ「設定 → 家 → 道具の列」の下で切れる
- **🎂 記念日**: 家の記念日。ぷちも自分で足せる。前の日に本人へ 1 回だけ伝わる
- **🫧 欲求**: 欲求の強さの移り変わり(3 日〜31 日)
- **🔔 音 / 📋 回覧板 / 📚 ライブラリ / 🔒 ひみつ / 📡 モニタ / 🖥️ ターミナル / 🔍 行動ログ / 💰 おかね**: 「ほか」の中。ふだんは使わない

## メール {#mail}

- **📬**: 受信 / 未読 / ⭐ / 📦。「＋」で書く。ぷちからの手紙は、読むと本人に「読まれた」と伝わる
- **スタンプ**: 手紙にスタンプ(5 つ)を付けられる。付けたことも本人に 1 回だけ伝わる

## 困ったとき {#trouble}

- **返事が来ない**: 2 分待つと「言葉にならなかったよ」→「もう一度きく」。それでも駄目なら「🔍 行動ログ」でその回を見る
- **声が出ない**: 体の音量(ようす)と、PSAVE がオンになっていないか、からだ おやすみ中でないか(📍)を見る
- **体が見えない**: ようす で確かめる。電源・Wi-Fi。しばらく待てば自動でつながる
- **設定が見当たらない**: 「… ほか」の中。列に出したければ「設定 → 家 → 道具の列」で「最初」に
- **ぷちが思ったように動かない時間帯**: その子の設定の「1 日に動く予定」と注意の帯を見る

## ことば {#words}

- **ひとりの時間 / 自律行動**: 人が話しかけていないときに、ぷちが自分で考えて動く回(cron で 30 分ごとに起き、アクティブタイムなら動く)
- **アクティブタイム**: ひとりの時間に動いてよい時間帯
- **からだ おやすみ**: カメラ・声・効果音を止めること。考えるのは止めない
- **PSAVE(お出かけ)**: 体の省電力 + 消音
- **CAM TO / WHO**: 体の記録を「だれの」と見なすかの設定
- **MAX_TURNS**: 1 回の自律行動の手数の上限
